Documentação Técnica Oficial

1. Resumo do Projeto

O presente projeto constitui a entrega final para avaliação da disciplina. A interface foi projetada utilizando conceitos de Mobile First e responsividade avançada, garantindo uma renderização perfeita tanto em dispositivos móveis quanto em computadores de mesa.

2. Decisões Arquiteturais e Tecnologias
  • HTML5 & CSS3: Utilizados para a marcação semântica e estilização customizada focada na paleta institucional (Azul e Branco).
  • Bootstrap 5.3: Framework escolhido pela facilidade na construção do Grid e dos componentes flutuantes (Modais).
  • JavaScript Vanilla: Manipulação de eventos simples, sem necessidade de bibliotecas pesadas.
3. Controle de Versão (Git)

Para o desenvolvimento em equipe, as seguintes práticas foram adotadas no fluxo de trabalho:

// Clonando o repositório principal
> git clone https://github.com/usuario/projeto-afya.git

// Criando e isolando a branch de desenvolvimento da interface
> git switch -c feature/interface-web

// Atualizando a branch com a base (main)
> git pull origin main
